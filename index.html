Peplum Grist widgets

Custom widgets for the peplum film library document. Paste one of these URLs into a Grist Custom widget's Enter Custom URL box.

  • frame-compare.html — synchronised frame comparison across releases. Attach to Stills, select by FrameSets.
  • scene-matrix.html — scenes × releases grid, click to set presence. Attach to Films, needs full document access.
  • gallery.html — searchable stills gallery. Attach to Stills.

Source and setup notes: see the repository README.
