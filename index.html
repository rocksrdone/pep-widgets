Peplum Grist widgets

Paste one of these URLs into a Grist Custom widget's Enter Custom URL box.

Entry

  • release-add.html — one form that writes a release plus all its audio and subtitle tracks. Attach to Films.
  • scene-logger.html — log a scene difference and mark every release at once. Attach to Films.
  • credit-add.html — add a credit, searching existing people by alias or creating them inline. Attach to Films.

Browse & compare

  • film-dashboard.html — everything about one film on a page. Attach to Films.
  • frame-compare.html — synchronised frame comparison. Attach to Stills, select by FrameSets.
  • scene-matrix.html — scenes × releases grid with thumbnails. Attach to Films.
  • gallery.html — searchable stills gallery. Attach to Stills.

All need Full document access except gallery and frame-compare, which need Read selected table (or full, if your instance requires it for attachments).
